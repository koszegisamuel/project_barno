# What is Project Barno
The name Barno simply comes from Barnabás + Piano and the purpose of this repository is to create
a real time desktop application for playing piano with a Midi device. The goal is to have tool with what
people could practice freely piano, load songs and learn them with instant feedback.

# MVP Requirements
Obviously a tool like this could be very complex and hopefully it will be however it is important
to pin down some core functionalities the tools should have in order to provide a minimum value

## Basic features

[ X ] Recognise MIDI input real time

[ X ] Has Piano sound kit for real time playing

[ X ] Is able to import simple MIDI files

[ X ] Is able to play imported MIDI

[ X/0 ] Has basic tempo and volume control

[ X ] Has a general graphical user interface to visualize the piano and notes

## Additional features
[ X ] Rewind and forward jump in the player

[ X ] Instant Feedback - show on GUI immediately if key was hit

[ X ] Calculate general hit ratio result at the song end

[ - ] Youtube to MIDI convert function - won't do due to technical reasons

[ 0 ] Record and replay practice (MIDI)

[ 0 ] Support for music sheet view with feedback
